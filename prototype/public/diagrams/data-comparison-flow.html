Glossary สำหรับ Dev & QA

ชื่อ enum และวิธีเปรียบเทียบตรงตามโค้ดจริง — ใช้เทียบตอนเขียนเทสต์หรือ debug สถานะ

Job Status

JobStatus — สถานะภาพรวมของงาน 1 job

NEWรอไฟล์ครบ (Pending Files)
PENDINGรอดำเนินการ
PROCESSINGกำลังเปรียบเทียบข้อมูล
REVIEWรอตรวจสอบ
READYเสร็จสมบูรณ์ พร้อมส่งออก
DONEส่งออกแล้ว (Exported)
REJECTEDถูกตีกลับจาก Job ถัดไป

Document Status

ComparisonDocStatus — สถานะของไฟล์แต่ละ column

MISSINGยังไม่มีไฟล์อัปโหลด
RECEIVEDอัปโหลดแล้ว รอ OCR
EXTRACTINGOCR กำลังสกัดข้อมูล
MATCHEDข้อมูลตรงกันตามกฎเปรียบเทียบ
MISMATCHEDข้อมูลไม่ตรงกัน ต้องตรวจสอบ
LOCKEDล็อกแล้ว แก้ไขไม่ได้ (เช่นหลัง Export)

Compare Methods

วิธีเปรียบเทียบใน Rule Matrix ต่อ field

EXACTตรงกันทุกตัวอักษร (normalize + trim + case-insensitive)
FUZZYเทียบความคล้ายเป็น % — threshold ปรับได้ 0–100
BILINGUALแปลความหมายด้วย AI ก่อนเทียบ ข้ามภาษาได้
NUMBER_WORDแปลงเป็นตัวเลขก่อนเทียบ รองรับเลขไทย/comma
EXISTENCEเช็คว่ามีข้อมูลอยู่หรือไม่ ไม่เทียบค่า
MASTER_LOOKUPค้นหาความถูกต้องจาก Master Data / Doc Type อื่น
CONDITIONALเทียบแบบมีเงื่อนไข ขึ้นกับค่า field อื่นก่อน
DATE_NORMALIZATIONปรับรูปแบบวันที่ให้ตรงกัน (พ.ศ. / ค.ศ.)
