เตรียม Shipment

Lane 1

01เข้าหน้ารายการงาน กด "สร้างรายการใหม่"
02เลือก Preset (ล็อกลำดับ Workflow) หรือกำหนดเอง แล้วตั้งชื่อ Shipment
03ระบบสร้าง Job ย่อยตามลำดับ Workflow ให้อัตโนมัติ

อัปโหลด & เปรียบเทียบ

Lane 2

04เปิด Job แรกในลำดับ เข้าหน้าเปรียบเทียบข้อมูล
05อัปโหลด/แทนที่ไฟล์ต่อคอลัมน์ Doc Type พร้อมเลือก Template
06ระบบ OCR แล้วเทียบตามกฎใน Rule Matrix ต่อฟิลด์

ส่งออก

Lane 3

07ถ้าพบ Mismatch ต้องแก้ก่อน ถึงจะกด Export ได้
08เลือก Workflow / Platform ปลายทาง (เช่น FTA) แล้วยืนยันส่งออก
09Job เปลี่ยนสถานะเป็น DONE / EXPORTED, ปลดล็อก Job ถัดไปในลำดับ
